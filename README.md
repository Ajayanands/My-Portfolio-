## 🏗️ Core Architecture

This project was built from scratch without heavy UI frameworks, relying on core web technologies and mathematics:

* 
**Liquid Glass Refraction Engine:** A custom mathematical engine that calculates a 2D Signed Distance Field (SDF) based on cursor proximity, feeding into an SVG `<feDisplacementMap>` to create realistic, real-time glassmorphism.


* **Procedural WebGL Brain:** The interactive 3D brain isn't a static `.gltf` model. It is generated procedurally using an `IcosahedronGeometry` and custom GLSL vertex shaders applying 3D Simplex Noise.


* **Three.js Neural Matrix:** A background scene rendering 250 dynamic particles. The CPU calculates distances between nodes on every frame to draw connecting lines, pushed through an `EffectComposer` with Unreal Bloom and Glitch Aberration shaders.


* **Ajay's Neural Twin (Client-Side RAG):** A custom AI chatbot integrated directly into the UI. Powered by the Google Gemini API, it uses a localized context prompt to answer questions about my background, skills, and projects, complete with agentic DOM-control to automatically scroll the user to relevant sections.

## 💻 Local Setup

If you want to clone this repository and explore the code locally:

1. Clone the repo:
```bash
git clone https://github.com/Ajayanands/My-Portfolio-.git

```


2. Because the AI Assistant utilizes the Google Gemini API, you will need to supply your own API key to test the chatbot locally. Replace `YOUR_API_KEY_HERE` in `index.html` with your generated `AIzaSy...` key from Google AI Studio.


3. Open `index.html` using a local server (like the VS Code "Live Server" extension) to prevent browser CORS policies from blocking the API requests.
